CSI-2300 Hangman Game

1. About the Project
For my CSI project I have chosen a Hangman game for this assignment.  Hangman is a game where players try to guess a hidden word one letter at a time. The goal is to guess the word before running out of chances.

2. How to Play the Game
1. Start the game.
2. Guess one letter at a time.
3. Correct guesses reveal the letter in the word.
4. Incorrect guesses reduce your remaining chances.
5. Guess the full word to win!

3. How to Run the Hangman Game
1. Download the project from GitHub.
2. Open the project in your coding program.
3. Run the main file to start the game.

4. Coding Tools Used to make my Game
- I used Apache Netbeans for this assignment
- I used Java for this assignment
